# Dati degli esercizi

Ogni esercizio ha la propria sottocartella. Gli studenti scaricano
i file da qui e li caricano in Microsoft 365 Copilot Chat.

| Cartella | Esercizio | Contenuto |
|---|---|---|
| `esercizio_01_dati/` | Esercizio 1: come si usa l'AI in Italia? | 3 screenshot PNG dell'Anthropic Economic Index, due obbligatori e uno facoltativo |
| `esercizio_03_dati/` | Esercizio 3: dal dato grezzo alla presentazione | 1 file CSV con 1.500 recensioni di vini italiani |

L'esercizio 2 non richiede allegati: usa soltanto i prompt della guida.

Ogni sottocartella contiene un proprio `README.md` con la descrizione
dei file, i valori di riferimento per il docente e i limiti dei dati.
